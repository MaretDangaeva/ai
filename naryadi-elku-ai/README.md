# 🎄 Наряди ёлку! — игра по искусственному интеллекту

**Готовая интерактивная браузерная игра для уроков в 1–4 классах.**

Дети отвечают на вопросы об искусственном интеллекте, получают ёлочные украшения и сами размещают их на виртуальной ёлке. Игра подходит для работы на интерактивной доске, проектора или индивидуально на телефоне/компьютере.

## Как играть

1. Выберите возраст: **1–2 класс** или **3–4 класс**.
2. Выберите продолжительность: **6 заданий** (примерно 5–8 минут) или **12 заданий** (примерно 10–15 минут).
3. Нажмите **«Начать игру»** и выберите правильный ответ. Если ответ неверный, появится дружелюбная подсказка, можно попробовать ещё раз.
4. Выберите игрушку (красный шар, золотая звезда, снежинка или фиолетовый шар) и нажмите на свободное место на ёлке. Если игра идёт с проектора, можно использовать кнопку **«Повесить автоматически»**.
5. После всех заданий ёлка засияет, а на экране появится вопрос для рефлексии.

**Дополнительно:** клавиши **1**, **2**, **3** выбирают ответы. Звук изначально выключен и включается значком динамика. В игре нет регистрации, рекламы, аналитики и отправки данных.

## Публикация на GitHub Pages — без программирования

1. Создайте новый **публичный репозиторий** на [github.com/new](https://github.com/new), например `naryadi-elku-ai`.
2. Распакуйте архив. На странице репозитория нажмите **Add file → Upload files**.
3. Перетащите **все файлы из папки** в корень репозитория: `index.html`, `styles.css`, `questions.js`, `app.js`, `favicon.svg`, `README.md`. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)**. Сохраните.
5. После публикации GitHub покажет адрес сайта, обычно `https://ВАШ_ЛОГИН.github.io/naryadi-elku-ai/`.

> Если репозиторий уже создан, достаточно загрузить файлы из архива в его корень. Никаких `npm install`, сервера или ключей API не требуется.

## Запуск без GitHub

Просто откройте `index.html` двойным щелчком: игра работает в современном браузере **без интернета**. Необходимы все файлы в одной папке.

## Темы вопросов

- Что такое ИИ и где он встречается.
- Как ИИ учится на примерах.
- Как задавать понятные вопросы (промпты).
- Почему ответы ИИ могут быть ошибочными и как их проверять.
- Личные данные, пароли, фотографии и безопасность.
- Человек и ИИ: сотрудничество, творчество, ответственность.

В каждом уровне есть **12 вопросов**. Для режима из 6 вопросов половина заданий выбирается случайным образом, поэтому повторные игры могут отличаться.

## Как преподавателю изменить вопросы

Откройте **`questions.js`** в любом текстовом редакторе. В нём два массива: `junior` (1–2 класс) и `senior` (3–4 класс).

Пример вопроса:

```js
{
  topic: "🤖 Что умеет ИИ?",
  question: "Может ли ИИ помогать искать информацию?",
  options: ["Да", "Нет", "Только зимой"],
  correct: 0,
  hint: "Подумай об умных помощниках.",
  explanation: "ИИ может помогать искать и объяснять информацию, но её нужно проверять."
}
```

Значение `correct` — номер правильного ответа, **начиная с нуля** (`0` — первый, `1` — второй, `2` — третий). Сохраняйте запятые между вопросами. Для полного режима необходимо минимум 12 вопросов на уровень.

## Технические особенности

- Обычные HTML, CSS, JavaScript и SVG, **без библиотек и внешних ресурсов**.
- Адаптирована под компьютер, планшет и телефон.
- Работает с клавиатуры; поддерживает настройки уменьшения анимации.
- Иллюстрации и украшения — векторные, не требуют загрузки изображений.
- Без API ИИ: вопросы заранее подготовлены, никаких токенов и платных сервисов.

Проект можно свободно использовать и адаптировать для школьных занятий.
