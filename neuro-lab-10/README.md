# НейроЛаб — 10-минутная игра про ИИ (урок 23)

Самостоятельная браузерная игра на время ожидания генерации видео в Leonardo. Для 1–4 классов, без аккаунтов, библиотек, подключения к серверу или внешних ресурсов.

## Как играть

1. Откройте `index.html` в браузере или страницу GitHub Pages.
2. Выберите уровень «1–2 класс» или «3–4 класс».
3. Пройдите 12 коротких заданий: картинки, видео, проверка ИИ, создание мини-промпта.
4. Получите результат из 120 баллов и скопируйте итоговый промпт.

## Время и данные

Таймер рассчитан на 10 минут. По истечении времени игру можно спокойно завершить. Отметки и прогресс сохраняются только в localStorage на устройстве ученика; никаких ответов на сервер и преподавателю автоматически не отправляется. Кнопка «Начать заново» сбрасывает прогресс. Работает без сборки и без интернета после загрузки страницы.

## GitHub Pages

Разместите эту папку в публичном репозитории с Pages, настроенным на `main` и `/(root)`.
