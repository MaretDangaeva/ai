# Нейрополис — Финальная миссия

Итоговый интерактивный тренажёр по курсу ИИ для 5–9 классов (уроки 1–32).

**[Открыть игру на GitHub Pages](https://maretdangaeva.github.io/ai/neuropolis-final/)**

- 20 минут, 21 задание, 7 тематических районов, максимум 210 баллов.
- Выбор ответа, несколько верных вариантов, сопоставление и последовательность.
- Видны текущие баллы и финальный результат, включая процент выполнения.
- Прогресс хранится только в браузере учащегося; регистрация и сервер не нужны.
- Результат можно скопировать и отправить преподавателю.

## Размещение

Файл `index.html` самодостаточен — библиотеки и сервер не требуются. Для публикации в этом репозитории GitHub Pages должен использовать ветку `main`, каталог `/(root)` (Settings → Pages → Deploy from a branch). Доступный ученикам адрес: `https://maretdangaeva.github.io/ai/neuropolis-final/`.

Для локального запуска достаточно открыть `index.html` в браузере.

Баллы рассчитываются на устройстве ученика; общего журнала результатов нет.
